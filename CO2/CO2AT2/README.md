# CSA43 CO-2 Assessment Tool 2 - Design Task

Internet Programming (CSA43), SIMATS Engineering. One responsive page that answers all five design questions with live demos.

| Question | Topic | Where on the page |
|----------|-------|-------------------|
| Q1 | Responsive navigation bar (hamburger menu) | Top navbar and Q1 section |
| Q2 | Product hover effect | Q2 cards |
| Q3 | Dashboard: Flexbox vs Grid | Q3 live dashboard |
| Q4 | Mobile-first blog layout | Q4 blog |
| Q5 | JavaScript event handling for a dynamic menu | Q5 menu with event log |

Each section includes the written answers (a) to (d).

## Run
Open `index.html` in any browser. Resize the window to see the layouts adapt.

## Technologies
HTML5, CSS3 (Flexbox, Grid, transitions, media queries), JavaScript (DOM events).
